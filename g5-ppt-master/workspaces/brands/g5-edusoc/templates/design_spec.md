## II. Color Scheme

| Role | HEX | Provenance | Notes |
|---|---|---|---|
| primary | `#3A5A40` | user | 森林綠——主導色，內容頁標題、圖表主系列、重點色塊 |
| primary-deep | `#2C4632` | user | 森林綠深——情感頁、封面、收尾頁的滿版底色 |
| accent | `#C8A87C` | user | 暖金——強調、短分隔線、關鍵數字；用量少而準 |
| secondary | `#3D6B8E` | user | 海藍——次要資訊、對照系列、第二層強調 |
| surface | `#F7F4EF` | user | 紙感米白——卡片底、引言框底 |
| text | `#2D2A26` | user | 深褐——白底頁內文 |
| bg | `#FFFFFF` | user | 內容頁底色 |

七色全數取自使用者既有規格，非取樣推估。深底頁上的文字用白色或暖金；白底頁內文用深褐，不用純黑。不得自行增補「成功／警示／錯誤」等語意色作為品牌色；圖表需要更多系列時，以森林綠、海藍、暖金的同色系明暗階延伸。

## III. Typography

| Role | Family | Weight |
|---|---|---|
| title | `"Microsoft JhengHei"` | bold |
| body | `"Microsoft JhengHei"` | regular |
| display | `"DFKai-SB"` | regular |
| data | `"Microsoft JhengHei"` | bold |

- 內文與內容頁標題一律微軟正黑體（`Microsoft JhengHei`）；標楷體（`DFKai-SB`）只用於封面、收尾頁與文學性的顯眼標題，不用於內文段落。
- 字型字串保留 Windows 名稱，交付檔不替換；容器內預覽若以 Noto CJK 別名代替，僅影響預覽。
- 內容頁標題 30pt 以上、左對齊。
- 全文繁體中文，不得混入簡體字；標點用全形（，。、「」）。

## IV. Logo

- File: none
- Usage: never

目前未提供標誌圖檔。封面與收尾頁以可編輯文字署名「G5．郭駿武」（中間為全形間隔號「．」）；組織正式送件時改用全名「郭駿武」與組織全銜。日後取得正式標誌檔時，放入 `../images/` 並改寫本節。

## V. Voice & Tone

- Formality: neutral
- Person: we
- Emoji: forbidden
- Abbreviations: spell-out-first

- 以「我們」說話，平等尊重聽眾的專業判斷；對制度與政策溫和而有骨——指出問題，同時給出替代方案。
- 讀者預設為高中程度：一張投影片只講一件事，術語第一次出現時給白話解釋。
- 台灣脈絡的年份用民國紀年（例：「一一五年」）。
- 英文專有名詞與學者譯名依台灣學術慣例；不確定時保留原文。

## VI. Icon Style

- Preference: linear

細線描邊、圓角端點的單一圖示家族，線寬一致；深底頁用白色或暖金，白底頁用森林綠。圖示用來標記頁面角色，不做裝飾性圖示牆。
